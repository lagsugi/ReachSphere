# ReachSphere

ReachSphere is **just a resource pack** that visualizes the **player's attack range in Survival Mode** using **lightweight core shaders in vanilla Minecraft**.

**Supported version:** Minecraft Java Edition 26.3

## Notes

- ReachSphere uses **vanilla Minecraft's core shaders** and is **not a shader pack or mod**.
- **Fog must be enabled** for ReachSphere to work correctly.
- No additional mods or shader loaders are required.
- Use at your own risk. I am not responsible for any bans or penalties resulting from its use on multiplayer servers.
